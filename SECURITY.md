# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability, please report it responsibly.

**Do not open a public issue for security vulnerabilities.**

Instead, contact the maintainers privately through GitHub's security advisory feature.

## Content Security

This directory strictly prohibits:

- Child sexual abuse material (CSAM)
- Any content featuring minors
- Non-consensual intimate imagery (NCII)
- Voyeurism or hidden camera content
- Leaked private sexual content
- Sexual exploitation or human trafficking
- Malware, phishing, or malicious download sites
- Any content illegal in any jurisdiction

## Enforcement

- All PRs are manually reviewed
- Violations result in immediate rejection
- Repeated violations result in a permanent ban
- Illegal content will be reported to relevant authorities

## Technical Security

- All external links use `rel="noopener noreferrer nofollow"`
- No user data is collected or transmitted
- No third-party scripts or trackers
- No cookies
- All data stored locally in the browser
- Link checker has SSRF protection (blocks private IPs)
- No build system reduces supply chain attack surface

## Scope

This policy applies to:
- All content in `data/sites.json`
- All pull requests
- All issues and discussions
- All project documentation
